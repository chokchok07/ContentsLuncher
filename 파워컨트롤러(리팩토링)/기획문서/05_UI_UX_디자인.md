# 05. UI/UX 디자인 및 레이아웃 기획 (개정 4본)

본 문서는 중앙 통제 프로그램(Showroom Power Controller)의 사용자 화면 설계 및 레이아웃 구성을 정의합니다. 

특히 본 개정본에서는 기기 조작자가 개발자가 아닌 일반인 현장 스태프인 점을 고려하여, 기존의 텍스트 그리드 표(Table/List)를 전면 폐기하고 **비주얼 디바이스 카드(Device Card)**와 **원형 카운트다운 타이머(Circular Progress Timer)**를 배치한 직관적인 UI 설계로 수정하였습니다.

## 2. 일반인 사용자를 위한 비주얼 디자인 명세

### 2.1 디바이스 카드(Device Card) 상태 가시성
장비들의 복잡한 통신 수치를 일반인이 보기 쉽게 직관적인 상태 카드로 도식화합니다.

1. **정상 가동 (ONLINE)**
   * **UI 표현**: 카드 전체 테두리가 은은한 연초록색 빛으로 빛나며 서서히 밝아졌다 어두워지는 맥박(Pulse) 호흡 효과 렌더링.
   * **텍스트**: 단순하고 명확하게 `"● 정상 작동 중"`만 표시.
2. **전원 꺼짐 (OFFLINE)**
   * **UI 표현**: 카드 전체가 불투명도 50%의 옅은 회색 테마로 어두워지며 아이콘이 비활성 표시됨.
   * **텍스트**: `"○ 전원 꺼짐"` 표시.
3. **오류 / 프리징 (FREEZE & CRASH)**
   * **UI 표현**: 카드 전체가 강렬한 빨간색 테두리로 전환되며 0.5초 주기로 빠르게 깜빡거리는 경고(Blink) 피드백 제공.
   * **텍스트**: `"🚨 확인 필요(오류)"` 표시.

### 2.2 지연 시간(Delay) 및 예열/식히기의 원형 카운트다운 타이머
기기가 부팅 대기(WOL Delay) 상태이거나 프로젝터가 팬을 돌려 식는(Cooling) 중일 때의 비주얼 피드백 방식입니다.

* **원형 진행 링 (Circular Progress Ring)**:
  * 카드의 장치 아이콘 테두리를 도넛 모양의 원형 진행바(주황색/황색)가 감쌉니다.
  * 지연 시간이 지나감에 따라 시계 방향으로 도넛 링이 서서히 깎여나가며 소멸하는 시각 피드백을 제공합니다.
* **중앙 남은 시각 노출**:
  * 아이콘 하단에 큼직한 타이머(`09초` 또는 `04:59`)만 크게 노출시켜, 일반인이 남은 잔여 대기시간을 직관적으로 읽을 수 있도록 편의성을 보장합니다.

## 3. UI 구현 기술 규격 (WinForms GDI+ 커스텀 렌더링)
* **GDI+ 더블 버퍼링**:
  * 깜빡임 없는 카드 뷰의 맥박(Pulse) 애니메이션과 원형 링(Progress Ring) 회전 그래픽 처리를 위해 WinForms의 `Paint` 이벤트에서 GDI+ 그래픽 드로잉 기법을 사용하며, 더블 버퍼링을 강제합니다.
* **이식성**:
  * 기존 **[런처 프로그램](file:///c:/Users/user/Documents/VSCode/실행기/런처 프로그램)**이 적용한 둥근 모서리 UI 드로잉 유틸리티 클래스를 그대로 상속받아 버튼 및 카드의 라운드 코너를 동일하게 표현합니다.
