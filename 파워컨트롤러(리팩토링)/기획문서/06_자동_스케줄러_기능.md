# 06. 자동 전원 스케줄러(Scheduler) 기능 기획 (개정 2본)

본 문서는 시연실의 정해진 운영 시간표(요일별 오픈/마감 시각)에 맞춰 마스터 프로그램이 자동으로 기기 전원을 켜고 끄는 **자동 스케줄러(Auto Scheduler)** 기능의 설계 및 작동 명세를 정의합니다. 특히 특정 요일 기동을 무조건 차단하는 기능과 요일별 사용자 정의 시간표 입력 기능이 결합되어 있습니다.

---

## 1. 스케줄 데이터 모델 정의

설정 파일(`devices.json`)의 `SchedulerSettings` 내에 특정 요일 무조건 차단 리스트와 요일별 시간표 입력을 위한 속성을 구성합니다.

### 1.1 JSON 스케줄 노드 예시
```json
{
  "SchedulerSettings": {
    "AutoScheduleEnabled": true,
    "IgnoreDaysOfWeek": [
      "Monday"
    ],
    "WeeklySchedules": [
      {
        "DayOfWeek": "Tuesday",
        "OnTime": "08:50",
        "OffTime": "18:10",
        "Description": "화요일 정상 시간표"
      },
      {
        "DayOfWeek": "Wednesday",
        "OnTime": "08:50",
        "OffTime": "18:10",
        "Description": "수요일 정상 시간표"
      },
      {
        "DayOfWeek": "Saturday",
        "OnTime": "09:50",
        "OffTime": "15:10",
        "Description": "토요일 단축 시간표 (사용자 개별 정의)"
      }
    ],
    "SpecificHolidays": [
      "2026-01-01",
      "2026-10-03"
    ]
  }
}
```

### 1.2 옵션 설명
* **IgnoreDaysOfWeek (무조건 실행 무시 요일 리스트)**: 이 배열에 지정된 요일(예: `Monday`)은 스케줄 예약 시간과 무관하게 **아침/저녁 전체 전원 제어 자동 실행이 100% 무시 및 차단**됩니다. 정기 휴관일 등에 대해 이중으로 안전장치를 제공합니다.
* **WeeklySchedules (요일별 사용자 정의 시간표)**: 사용자가 각 요일마다 원하는 시간(`OnTime`, `OffTime`)을 직접 입력해 스케줄을 개별 커스텀하는 리스트입니다. 여기에 기재되지 않은 요일도 자동으로 스케줄 작동이 생략됩니다.

---

## 2. 감시 및 필터링 제어 흐름 (Scheduler Logic Flow)

매분 주기적 시간 검사 루틴에서 필터링을 수행하는 2단계 검증 흐름입니다.

### 2.1 1단계: 무조건 무시 요일 검사 (Ignore Check)
1. 백그라운드 스케줄러가 동작하면, 먼저 오늘의 요일(예: `Monday`)을 감지합니다.
2. 오늘의 요일이 `IgnoreDaysOfWeek` 배열 리스트에 등록되어 있는지 검사합니다.
3. 존재할 경우, 시간 비교 단계로 진입하지 않고 **그 즉시 스케줄 감시 스레드를 당일 자동 종료(Bypass)**합니다.
   * *효과: 월요일이 정기 휴관일이면, 시간표 설정에 월요일 설정이 어떻게 되어있든 상관없이 패킷을 절대 쏘지 않고 확실히 동작을 정지합니다.*

### 2.2 2단계: 사용자 지정 시간표 매칭 (Schedule Matching)
1. 1단계 필터를 무사히 통과한 요일(예: `Saturday`)의 경우, `WeeklySchedules` 리스트 내에서 해당 요일에 매칭되는 노드를 검색합니다.
2. 사용자가 입력해 둔 특정 `OnTime`(예: `09:50`) 또는 `OffTime`(예: `15:10`)에 도달했는지 현재 시각과 비교합니다.
3. 해당 시각에 도달하면 비동기로 **[ALL ON/OFF 매크로]**를 트리거합니다.
4. 요일 리스트에 존재하지 않는 요일 또한 기본적으로 실행 명령이 무시됩니다.

---

## 3. UI/UX 구현 명세 (설정 창 연동)

* **사용자 직접 입력 인터페이스**:
  * 설정 팝업 창에 **"요일별 자동 스케줄 시간표"** 표(Grid/List)를 노출합니다.
  * 요일별로 켜기(`OnTime`), 끄기(`OffTime`) 텍스트 박스를 제공하여 관리자가 원하는 요일의 시간을 직접 타이핑하여 등록하고 `[스케줄 저장]` 버튼을 누르면 `devices.json`에 즉각 기록되도록 설계합니다.
  * 요일별 무조건 차단 설정은 체크박스로 제공해, 체크 시 해당 요일이 `IgnoreDaysOfWeek` 목록에 들어가도록 연동합니다.
