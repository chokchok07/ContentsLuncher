# [Part 1] GUI 디자인 시스템 및 DPI 스케일링 대응 사양

전시장 및 쇼룸 환경에 최적화된 고품질 다크 테마 GUI 레이아웃 설계와 다양한 해상도/배율에서 깨짐 없이 정갈하게 동작하는 UI 메커니즘 분석서입니다.

---

## 🎨 1. 프리미엄 다크 모드 디자인 테마 규격
눈의 피로도를 최소화하고 콘텐츠 시인성을 높이기 위해 엄격히 조율된 다크 그레이 계열의 팔레트가 구현되어 있습니다.

* **메인 백그라운드 색상**: `Color.FromArgb(15, 16, 25)` (매우 어두운 다크 네이비 그레이)
* **시연 콘텐츠 카드 배경색**: `Color.FromArgb(28, 29, 43)` (입체감을 부여하기 위한 밝은 다크 네이비)
* **카드 기본 테두리 색상**: `Color.FromArgb(37, 39, 54)`
* **입력 텍스트 박스 배경색**: `Color.FromArgb(20, 21, 33)` / 전경색: `Color.White`
* **주요 액션 버튼 (실행/저장)**: `Color.FromArgb(123, 97, 255)` (세련된 퍼플 블루)
* **상태 경고/종료 버튼**: `Color.FromArgb(239, 68, 68)` (가시성 높은 레드)
* **대기 상태/경고 버튼**: `Color.FromArgb(245, 158, 11)` (골드 오렌지)
* **'종료 시 PC도 끄기' 버튼의 대비성**: 가독성을 높이기 위해 명도 대비를 확실히 둔 흰색(`Color.White`) 폰트 색상을 지정했습니다.

## 🖌️ 2. GDI+ 기반 둥근 모서리 및 더블 버퍼링 기법
Windows Forms의 정형화된 직사각형 컨트롤 한계를 극복하기 위해 커스텀 그래픽스 처리가 입혀져 있습니다.

### 커스텀 둥근 테두리 렌더링 (`CreateCardPanel`)
* 폼과 카드가 다시 그려질 때 `Paint` 이벤트를 가로채어 `GraphicsPath`에 아크(`AddArc`)를 추가해 둥근 모서리를 정밀하게 깎아냅니다.
* `e.Graphics.SmoothingMode = SmoothingMode.AntiAlias;` 설정을 활성화하여 거칠고 픽셀이 계단식으로 깨지는 현상을 방지하고 매끄럽게 처리합니다.

### 플리커 프리 (깜박임 방지) 구조
* 타이머에 의해 1초마다 상태등이 다시 그려질 때 화면이 깜박(Flicker)거리는 문제를 차단하고자 `Panel` 클래스를 상속받은 `DoubleBufferedPanel` 사용자 정의 컨트롤을 사용합니다.
* `this.DoubleBuffered = true;` 설정을 인스턴스 생성자에서 활성화하여, 백 버퍼에서 메모리 그리기를 완성한 뒤 화면에 한 번에 렌더링해 껌벅임 없는 매끄러운 갱신을 보장합니다.

## 📐 3. High DPI 자동 배율 대응 및 마진 설계
Windows 디스플레이 배율(125%, 150%, 200% 등)이 적용된 고해상도 모니터에서도 텍스트와 컴포넌트가 침범하거나 겹치지 않게 방어합니다.

### OS 수준의 High DPI 모드 및 매니페스트(Manifest) 바인딩 활성화
* **Per-Monitor DPI V2 설정**: `app.manifest` 매니페스트 파일을 컴파일러 옵션(`/win32manifest:app.manifest`)으로 실행 파일 내부에 빌드하여 통합했습니다.
* 이를 통해 Windows OS가 이 실행 파일을 실행하는 즉시 **가장 최신의 모니터별 고해상도 V2 인식 프로그램**으로 강제 규정합니다.
* 보조 백업으로 런처 진입점(`Main()`)에서도 `SetProcessDPIAware()`를 병행 구동합니다.
* 결과적으로 사용자가 윈도우 디스플레이 배율을 **150%나 200% 등으로 적용한 고해상도 상태에서도 글씨 깨짐(흐려짐)이나 UI 컴포넌트 겹침 현상이 완전히 소멸하고 본연의 고유 해상도 디자인 시스템을 깨끗하게 보정 유지**합니다.

### 물리 가로 좌표 마진(Margin) 충돌 예방 설계
* 배율 증가 시 글꼴 길이가 길어져 우측의 ON/OFF 버튼을 가리지 않도록 가로 오프셋(X 좌표)을 충분히 여유 있게 이격 배치했습니다.
  * **선행 구동 모듈 토글**: 라벨과 버튼의 간격을 늘려 ON 버튼 위치를 `220`으로, OFF 버튼을 `275`로 충분히 후퇴시켰습니다.
  * **포커스 유지 토글**: ON 버튼 X 위치를 `180`으로, OFF 버튼 위치를 `235`로 넉넉하게 밀어 글자가 잘리는 현상을 방지했습니다.
  * **포커스 유지 설명문**: 토글 버튼 우측과 간격을 벌려 `295` 좌표부터 텍스트가 표시되게 조율했습니다.
  * **커스텀 테두리 크기 조절 시스템 (Sizable None) 도입**: 캡션바 디자인 보존을 위해 `FormBorderStyle.None` 상태를 지키되, 윈도우 OS 하부 메시지인 `WM_NCHITTEST`를 감시 재정의하여 테두리를 마우스 드래그로 늘리면 실시간으로 창 사이즈가 조절되는 전용 크기 조절 기능을 탑재했습니다.
  * **반응형 컴포넌트 앵커 (Anchor) 설계**: 창이 늘어날 때 우측 닫기/최소화 및 저장/취소 액션 버튼들과 메인 흐름 카드 패널이 정확히 정비례하여 화면 하단 및 우측을 졸졸 밀착 추종하도록 `Anchor` 관계망을 완벽하게 재조율했습니다.

## 👁️‍🗨️ 4. 콘텐츠 아이콘/이모지 실시간 미리보기 (Preview) 사양
콘텐츠 정보 편집기(`EditForm`) 내에서 아이콘을 지정하는 즉시 시각적 유효성을 미리 파악할 수 있도록 프리미엄 미리보기 전용 패널을 제공합니다.

* **디자인**: 다크 모드 전용 다크 인레이 패널(`Color.FromArgb(15, 16, 25)`)에 둥근 모서리 반경 8px 테두리를 둘러 고급스러움을 극대화했습니다.
* **로컬 파일 자동 로딩**: 입력된 경로가 로컬 파일(`File.Exists`)인 경우, `PictureBox` 컴포넌트를 스케일 줌(`PictureBoxSizeMode.Zoom`) 모드로 켜서 이미지를 로드합니다.
* **이모지/텍스트 자동 렌더링**: 파일이 아닐 경우, `Segoe UI Emoji` 14pt 폰트로 레이블을 활성화하여 중앙 정렬된 직관적인 아이콘 형태로 선명하게 그려냅니다.
