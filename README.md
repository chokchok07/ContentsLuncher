# ⚡ Showroom Power Controller & Launcher
**시연실 및 전시장 통합 전원 제어 · 콘텐츠 관리 솔루션**

전시장, 팝업스토어, 행사장에서 운영되는 여러 대의 PC와 빔 프로젝터, 그리고 시연용 콘텐츠(게임, 미디어 아트 등)를 관리자가 중앙에서 한 번에 통제하고 모니터링할 수 있도록 돕는 경량형 자동화 솔루션입니다. 

비전공자인 일반인 현장 스태프도 직관적으로 이해하고 조작할 수 있도록 설계되었습니다.

---

## 🛠️ 주요 구성 요소

이 시스템은 크게 **명령을 내리는 조종석(마스터)**과 **명령을 받아 움직이는 대원(에이전트)** 구조로 나뉘어 동작합니다.

1. **통합 전원 제어반 (Master Controller)**
   * 관리자의 PC나 태블릿에서 실행되는 중앙 통제 프로그램입니다.
   * 전시장 전체, 혹은 '로비', '세미나실' 등 공간별로 기기를 한 번에 켜고 끌 수 있으며, 각 기기의 작동 상태를 실시간으로 모니터링합니다.
2. **런처 에이전트 (Agent Launcher)**
   * 전시장에 있는 각각의 시연용 PC마다 설치되는 숨은 조력자입니다.
   * 컴퓨터가 켜지면 시연 콘텐츠를 자동으로 실행하고 관람객이 다른 화면으로 나가지 못하게 화면을 보호하며, 10초마다 중앙 제어반에 "나 잘 살아있어!"라고 상태를 보고합니다.

## ✨ 핵심 기능 및 특징

### 1. 🔄 공간별 / 전체 원클릭 제어
아침마다 전시장의 모든 컴퓨터와 프로젝터를 일일이 켜고, 저녁마다 끄러 다닐 필요가 없습니다. 단 한 번의 클릭으로 전체 기기를 순서대로 안전하게 켜고 끌 수 있으며, 특정 구역(예: 로비)만 선택해서 통제할 수도 있습니다.

### 2. 🛡️ 똑똑한 시연 화면 보호 (관람객 이탈 방지)
관람객이 실수로 전시 프로그램을 끄거나 바탕화면으로 나가버리더라도, 1초 만에 즉시 시연 화면을 맨 앞으로 강제로 되돌려놓습니다. 반면 관리자가 직접 설정을 만질 때는 알아서 화면을 양보하여 편리한 조작을 돕습니다.

### 3. 💓 실시간 생사 확인 및 오류 감지 (하트비트)
단순히 컴퓨터의 전원이 켜져 있는지만 확인하는 것을 넘어, **실제 전시 프로그램이 멈추지 않고 잘 돌아가고 있는지**를 10초 단위로 감시합니다. 화면이 먹통(프리징)되거나 오류로 꺼지면, 중앙 제어반에 즉각 **"🚨 빨간불"**과 경고를 띄워 관리자가 바로 조치할 수 있게 합니다.

### 4. ⏰ 퇴근을 돕는 자동 스케줄러 & 원격 제어
* **자동 스케줄러**: 정해진 마감 시간이 되면 프로젝터를 먼저 식히고, PC를 끄는 등 안전한 순서에 맞춰 전시장의 모든 전원을 자동으로 셧다운시킵니다.
* **원격 제어**: 전시장 카운터 등에 설치된 중앙 전원 제어반(마스터 PC)을 통해 런처 에이전트와 통신하여, 멀리서도 각 기기의 시스템을 켜고(WAKEUP) 끌 수(SHUTDOWN) 있습니다.

### 5. 🚫 휴먼 에러 방지 (중복 실행 차단)
현장 스태프가 실수로 제어 프로그램을 여러 번 더블클릭해서 꼬이는 일이 없도록 방지합니다. 이미 켜져 있는 상태라면 프로그램을 또 켜지 않고, 화면 구석에 숨어있던 원래 창을 맨 앞으로 친절하게 당겨옵니다.

## 🚀 설치 및 빌드 방법 (개발자용)

무거운 개발 도구(Visual Studio 등)를 설치할 필요가 없습니다. 윈도우에 기본으로 내장된 기능만을 사용하여 1초 만에 빌드되는 무설치 환경을 제공합니다.

1. 저장소를 다운로드(Clone)합니다.
2. `런처프로그램(리팩토링)` 또는 `파워컨트롤러(리팩토링)` 폴더 안에 있는 **`build.bat` (또는 `build_controller.bat`)** 스크립트를 더블클릭합니다.
3. 컴파일이 성공하면 `빌드` 폴더(또는 해당 디렉토리)에 단일 실행 파일(`.exe`)이 생성됩니다.
4. 현장 PC에 배포할 때는 생성된 **`.exe` 실행 파일 하나만 복사해서 전달**하면 끝납니다!
